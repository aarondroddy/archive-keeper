# Security Policy

Archive Keeper is pre-release software that may move large numbers of files.

Before applying real changes:

1. Confirm all NAS shares are mounted.
2. Confirm mount points are not empty local directories.
3. Back up the rmlint report and Archive Keeper journal.
4. Inspect the plan.
5. Run a limited dry run.
6. Run and restore a small verified pilot.
7. Only then consider a larger operation.

Report vulnerabilities privately through GitHub Security Advisories. Do not
include credentials, access tokens, recovery keys, or unnecessary personal data.

Archive Keeper is not a replacement for backups.
